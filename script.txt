Hi, and welcome to our Cub3D demo!

Here, you can already see the main features of the rendering system.

The background is drawn once into an image
and this image is reused each frame for performance.

Then comes the raycasting engine that draws textured walls
with correct depth and perspective.

You'll also notice entities like NPCs and items. These are
depth-sorted and drawn in order so they overlap correctly.

For the kittens drawing, we choose the right
animation frame, based on both the player's orientation and the NPC's
movement direction.

Drawing pixel-by-pixel using MiniLibX's built-in function
is quite demanding, so instead of calling their
put_pixel function for every pix, we are writing the color values directly
into the image buffer.

This allows much better performance since it avoids function call overhead.

Then we have NPC dialogues and storyline that are dynamic too,
based on what the player sees or does. Each player can have a slightly
different run.

NPC moves are managed by a A* algorithm. The patrol system
uses randomly generated waypoints. The fireball can chase you in real time

The NPCs can also follow the player when it fits the narrative,
they're smart enough to open doors if they are on their path.

Another cool part of the project is a generic raycast utility
function that lets any entity or the player check what's in its surroundings.
Combined with is_facing_target function, it enables smooth and realistic
interactions between player, entities and the environment.

Overall, it’s been a fun and rewarding challenge to bring all these systems
together into a complete, interactive game.
Thank you for watching!
